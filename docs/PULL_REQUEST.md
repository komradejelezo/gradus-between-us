# ГРАДУС: Между нами — рабочая игра v0.1

Вместо репозитория с одним README добавлена полноценная локальная игра для двух взрослых на React, TypeScript и Vite. Можно настроить профили и комфортный уровень, пройти четыре этапа с 8/16/24 событиями, открыть один из 12 финалов и сохранить памятный результат.

Реализованы 90 авторских карточек в шести категориях, фильтрация по этапу, атмосфере и прикосновениям, тайные ответы с передачей устройства и двумя подтверждениями, кубик с совместимыми эффектами и бонусной картой-сюрпризом, временные модификаторы, пропуск и замена без повторов. Движок резервирует карточки при частых заменах, чтобы партия оставалась проходимой.

Адаптивный романтический интерфейс включает анимации карточек и раскрытия, частицы, градусомер, кубик, сокращённые анимации и необязательный локальный звук. Прогресс восстанавливается из LocalStorage; тайные ответы в сохранение не попадают. Есть пауза, правила и полное удаление данных игры.

Проверки в облачной среде:

- `npm ci --ignore-scripts --no-audit --no-fund --cache /tmp/gradus-npm-cache --offline` — установка из lockfile успешна.
- `npm test` — 31 тест пройден, включая все 18 сочетаний настроек и исчерпание замен.
- `npm run build` — TypeScript и production-сборка успешны.
- `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e` — 2 браузерных сценария на production-сборке: полная мобильная партия и настольное восстановление настроек.
- `npm run format:check` — успешно.

Исходное ТЗ находится в `docs/SPEC.md`, запуск и ограничения описаны в README. GitHub Actions проверяет код без публикации. `gradus-online` не затронут; Pages и другие публичные развёртывания не выполнялись.

Ограничения v0.1: только одно общее устройство; ответы скрываются интерфейсом, а не криптографией. Нет сервера и синхронизации устройств. При недоступном LocalStorage игра работает только до закрытия вкладки с предупреждением.
