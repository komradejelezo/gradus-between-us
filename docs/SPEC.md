# Техническое задание: ГРАДУС — Между нами

## 1. Задача

Создать полноценный интерактивный браузерный прототип романтической игры для двух взрослых «ГРАДУС: Между нами».

Игра должна быть визуально впечатляющей, современной, атмосферной и приятной для совместного времяпровождения.

Это отдельный продукт во вселенной «ГРАДУС». Не изменять существующий проект `gradus-online`, его репозиторий, GitHub Pages и рабочую версию.

Создать отдельный проект `gradus-between-us`. Репозиторий по возможности сделать приватным. Не публиковать игру в открытый доступ без отдельного разрешения.

## 2. Технологии

- React + TypeScript + Vite.
- Адаптивный интерфейс для телефонов, планшетов и компьютеров.
- LocalStorage для сохранения состояния партии.
- CSS-анимации или Framer Motion.
- Без обязательного сервера, регистрации и внешней базы данных.
- Без платных API.
- Все основные функции должны работать локально после сборки.

Архитектура должна позволять в будущем добавлять карточки, новые режимы и визуальные темы без переписывания основной логики.

## 3. Визуальный стиль

Создать премиальный романтический интерфейс.

Цветовая палитра:
- Глубокий бордовый `#350C23`.
- Тёмный сливовый `#190D24`.
- Розовое золото `#DFA58D`.
- Насыщенный малиновый `#E94B80`.
- Тёплый золотистый `#F4C78B`.

Использовать:
- Мягкие неоновые свечения.
- Эффекты стекла (glassmorphism).
- Элегантную типографику с поддержкой кириллицы.
- Плавные переходы между экранами.
- Анимированные карточки с эффектом переворота.
- Ненавязчивые частицы света.
- Мягкое свечение градусомера.
- Красивые анимации кубиков.
- Романтическую атмосферу без перегруженности интерфейса.

Главный экран должен выглядеть как дорогой цифровой романтический подарок.

Заголовок: **ГРАДУС**

Подзаголовок: **Между нами**

Слоган: **«Сегодня всё только для вас двоих»**.

Главные кнопки:
- Начать игру.
- Продолжить игру (при наличии сохранения).
- Настройки.
- Правила.

Интерфейс на русском языке. Предусмотреть возможность будущей локализации.

## 4. Настройка игроков

Ровно два игрока.

Каждый указывает:
- Имя.
- Аватар (выбор из готовых).
- Цвет или оформление своего профиля.

Настройки партии:
- Длительность: 15 / 30 / 45 минут.
- Атмосфера: Нежная / Игривая / Смелая.
- Задания с прикосновениями: включены / выключены.
- Анимации: полные / сокращённые.
- Звук: включён / выключен.

Основной режим для первого прототипа: **Смелая, 18+**.

При выборе других атмосфер фильтровать карточки по уровню откровенности. Не показывать недопустимые для выбранных настроек задания.

## 5. Игровая логика

Игра кооперативная. Победителя и проигравшего нет.

Основная цель — вместе заполнить градусомер и открыть романтический финал.

Пять этапов:
1. Искра.
2. Притяжение.
3. Химия.
4. Жар.
5. Между нами.

Для перехода между первыми четырьмя этапами требуется завершить четыре события.

Всего шестнадцать обычных событий, затем одно финальное.

Длительность задаёт темп и рекомендуемое количество событий, а не принудительное завершение по таймеру. В короткой партии использовать восемь событий (по два на этап), в стандартной шестнадцать (по четыре), в длинной двадцать четыре (по шесть).

Пятый этап всегда финальный.

После завершения события:
- Увеличивать прогресс.
- Обновлять визуальный градусомер.
- Передавать ход следующему игроку.
- Проверять переход этапа.
- Сохранять состояние.

Пропуск и замена задания не должны блокировать прохождение.

## 6. Категории карточек

Создать шесть категорий:

**Признайся** — вопросы, вызывающие улыбку, доверие и откровенный разговор.

**Угадай меня** — оба игрока независимо отвечают на вопрос, затем сравнивают ответы.

**Искушение** — романтический выбор из двух действий, согласованный обоими.

**Дуэль сердец** — короткое соревнование на знание предпочтений партнёра.

**Момент вдвоём** — совместные действия и небольшие романтические испытания.

**Сюрприз** — необычные игровые события и временные модификаторы.

Подготовить минимум **90 полноценных карточек**, по 15 каждой категории, распределённых по этапам и уровням откровенности.

Дополнительно подготовить 12 отдельных финальных карточек.

Каждая карточка должна иметь:
- Уникальный ID.
- Категорию.
- Этап доступности.
- Уровень откровенности.
- Название.
- Короткий текст.
- Тип взаимодействия.
- Возможные варианты ответов.
- Признак допустимости прикосновений.
- Признак использования кубика.
- Допустимые эффекты кубика.
- Условие завершения.

Все тексты должны быть оригинальными, разнообразными, естественными и понятными.

Избегать однообразных вопросов, чрезмерно длинных заданий и повторов в одной партии.

## 7. Примеры карточек

**Признайся — «Первое впечатление»**

«Какая моя черта показалась тебе особенно привлекательной при первой встрече?»

**Угадай меня — «Идеальное свидание»**

Оба тайно выбирают:
- Ужин при свечах.
- Спонтанное приключение.
- Уютный вечер дома.
- Неожиданный сюрприз.

Затем ответы раскрываются.

**Искушение — «Выбирай»**

«Что тебе приятнее прямо сейчас: услышать три необычных комплимента или получить маленький романтический сюрприз?»

**Дуэль сердец — «Читай мысли»**

«Назовите по очереди три вещи, которые делают обычный вечер романтическим. Сравните ответы».

**Момент вдвоём — «Минута только для нас»**

«На протяжении одной минуты рассказывайте друг другу, что особенно цените в ваших отношениях».

**Сюрприз — «Секретный комплимент»**

«До конца следующего этапа каждый должен придумать партнёру новое ласковое прозвище».

**Финал — «Наш вечер»**

«Каждый выбирает одно желание из трёх предложенных романтических вариантов. Затем вместе решите, как красиво завершить этот вечер».

## 8. Кубики судьбы

Создать виртуальный шестигранный кубик с анимацией.

Возможные эффекты:
1. Выполнить обычный вариант задания.
2. Поменяться ролями.
3. Получить дополнительный вопрос.
4. Выбрать один из двух вариантов задания.
5. Добавить романтическое условие.
6. Получить карту-сюрприз.

Эффекты должны быть совместимы с конкретной карточкой.

Если эффект неприменим, использовать заранее заданный безопасный вариант, а не ломать ход.

Кубик используется только на отмеченных карточках.

## 9. Система тайных ответов

Реализовать полноценную механику для одного общего устройства.

Последовательность:
1. Первый игрок выбирает ответ.
2. Ответ скрывается.
3. Появляется экран «Передай устройство партнёру».
4. Второй игрок выбирает ответ.
5. Оба подтверждают готовность.
6. Запускается красивая анимация раскрытия.
7. Показываются ответы обоих игроков.

При совпадении — специальная анимация сердечек.

При несовпадении — забавная или романтическая реакция.

Ответы не должны быть видны другому игроку до раскрытия.

## 10. Активные эффекты

Реализовать систему временных игровых модификаторов.

Примеры:
- До конца этапа обращаться к партнёру необычным прозвищем.
- Следующий вопрос задавать шёпотом.
- На следующем ходу поменяться ролями.
- Следующий комплимент произнести максимально торжественно.

Активные эффекты должны отображаться в интерфейсе, иметь понятный срок действия и автоматически исчезать.

## 11. Игровой экран

Основные элементы:
- Имена и аватары двух игроков.
- Название текущего этапа.
- Общий градусомер.
- Текущая карточка.
- Кнопка броска кубика, когда он требуется.
- Кнопки выполнения, замены и пропуска.
- Активные эффекты.
- Индикатор прогресса.
- Кнопка паузы и настроек.

Интерфейс должен быть удобным для использования одной рукой на телефоне.

Крупный текст, хорошие контрасты, минимум лишних элементов.

## 12. Финал

После завершения всех этапов запускать отдельную красивую финальную сцену.

Анимация заполненного градусомера, мягкое освещение, раскрытие финальной карточки.

Предусмотреть разные финальные события и случайный выбор без повторения предыдущих карточек.

После финала:
- Начать новую игру.
- Вернуться в меню.
- Посмотреть краткую статистику.
- Сохранить памятный результат локально.

Не сохранять интимные ответы и личные признания в статистике.

## 13. Комфорт и безопасность

- Все участники должны быть совершеннолетними.
- Любое задание можно пропустить без объяснения и штрафа.
- Прикосновения только по взаимному согласию.
- Никаких обязательных алкогольных заданий.
- Никаких опасных действий, принуждения, унижения или публикации личной информации.
- Предусмотреть кнопку «Сменить карточку».
- В настройках можно отключить задания с физическим контактом.
- Не требовать загрузки фотографий, телефонных номеров и личных данных.

## 14. Сохранение

Автоматически сохранять:
- Имена и аватары.
- Настройки.
- Текущий этап.
- Прогресс.
- Использованные карточки.
- Активные эффекты.
- Очерёдность игроков.

После перезагрузки страницы игра должна восстанавливаться корректно.

Предусмотреть возможность полностью удалить сохранение.

## 15. Тестирование

Обязательно проверить:
- Начало новой партии.
- Все три варианта длительности.
- Все уровни откровенности.
- Все шесть категорий карточек.
- Кубик и совместимость эффектов.
- Тайные ответы двух игроков.
- Пропуск и замену карточки.
- Переходы между этапами.
- Сохранение и восстановление.
- Финальное событие.
- Адаптивность для телефона.
- Отсутствие повторов карточек в партии.
- Корректность работы после сборки.

Добавить автоматические тесты ключевой игровой логики.

Предоставить:
1. Полностью работающий исходный проект.
2. Красивый адаптивный интерфейс.
3. Реализованную механику двух игроков.
4. Не менее 90 обычных карточек и 12 финальных.
5. Анимации и визуальные эффекты.
6. Рабочее локальное сохранение.
7. Инструкцию запуска.
8. Результаты сборки и тестирования.

Не ограничиваться статическим макетом или демонстрацией отдельных экранов.

**Главный критерий: пользователь должен иметь возможность начать игру, пройти все этапы и завершить полноценную партию без ошибок.**

Не изменять существующий проект «ГРАДУС ONLINE». Не публиковать новый проект без разрешения владельца.
