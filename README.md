# ГРАДУС: Между нами ❤️

Романтическая интерактивная игра для двух взрослых (18+).

Совместные испытания, флирт, откровенные вопросы, кубики судьбы и пять этапов развития романтической атмосферы.

## Технологии
React, TypeScript, Vite.

## Статус
Разработка первой версии (v0.1).

Проект независим от основной игры «ГРАДУС ONLINE».
