# ГРАДУС: Между нами ❤️

Романтическая кооперативная браузерная игра для **двух взрослых (18+)**. React + TypeScript + Vite. Версия 0.1, интерфейс на русском. Сервер, регистрация, платные API и внешняя база не нужны.

## Запуск

Нужен Node.js 22.12+ (проверено на 24) и npm.

```sh
npm ci
npm run dev
```

Команды выполняются из корня `gradus-between-us`. Vite выводит локальный адрес в терминал. Для локальной проверки production-сборки:

```sh
npm run build
npm run preview
```

`dist/` — самостоятельная статическая сборка. Её нужно открывать через HTTP-сервер, а не `file://`. После сборки приложение не обращается к внешним сервисам: нет удалённых шрифтов, аналитики или ресурсов. Никакой автоматической публикации или GitHub Pages в проекте нет.

## Как играть

1. Укажите имена, выберите аватары и цвета, подтвердите совершеннолетие и добровольное участие.
2. Выберите темп: 15 минут — 8 событий, 30 — 16, 45 — 24. Таймер не прерывает игру.
3. Пройдите «Искру», «Притяжение», «Химию» и «Жар» (по 2, 4 или 6 событий), затем общее финальное задание «Между нами».
4. Шесть категорий чередуются; новые карточки выбираются случайно из подходящего пула. В партии они не повторяются, включая заменённые карточки и бонусы кубика. При исчерпании замен игра резервирует карточки для завершения этапа.
5. Кубик появляется только на отмеченных карточках. Он добавляет совместимое условие; грань 6 открывает отдельную бонусную карту-сюрприз. Если бонус недоступен, применяется обычный вариант.
6. В «Угадай меня» первый игрок выбирает ответ, передаёт устройство второму, после второго ответа оба подтверждают готовность. Только затем ответы раскрываются. Партнёр должен отвернуться во время чужого выбора — это игра на доверии, не защищённая система обмена секретами.

**Любое задание можно пропустить без объяснений и штрафа.** Пропуск продвигает партию, замена оставляет тот же ход. Все прикосновения требуют согласия обоих; их можно полностью отключить до начала партии. Нежная атмосфера использует уровень 1, игривая — 1–2, смелая — 1–3. Участие добровольное, алкоголь и опасные действия не требуются.

## Сохранение и приватность

Прогресс автоматически сохраняется в LocalStorage этого браузера: профили, настройки, использованные карточки, эффекты, ход и результат кубика. Кнопка «Продолжить игру» восстанавливает партию. **Ответы и личные признания не записываются** — при перезагрузке тайный вопрос начинается заново. Хранилище браузера не зашифровано; не используйте имена, которые не хотите оставлять на общем устройстве.

Завершённые финалы учитываются, чтобы сначала предложить все 12 вариантов. Памятный результат сохраняется по желанию: дата начала, число событий и пропусков, ID финала (без имён и ответов). В настройках можно удалить все данные игры. При запрете хранилища игра продолжает работать в текущей вкладке с предупреждением.

## Проверки

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm run format:check
```

Если Chromium уже установлен, можно использовать его:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

Vitest проверяет каталог, все 18 комбинаций настроек, переходы, замену и исчерпание колоды, эффекты кубика, временные модификаторы, восстановление и финал. Playwright проверяет production-сборку на мобильном и настольном экранах: полную партию, тайные ответы с совпадением и различием, перезагрузку, удаление данных. CI выполняет эти проверки и **не развёртывает игру**.

## Структура

- `src/cards.ts` — 90 авторских карточек (15 в каждой категории) и 12 финалов с метаданными, включая уровень, этап, варианты и совместимые эффекты.
- `src/engine.ts` — независимые от React правила и проверка сохранений.
- `src/storage.ts` — ограниченные приложением ключи LocalStorage, история финалов, памятные результаты.
- `src/main.tsx` — экраны, передача устройства, подтверждения, анимированный кубик, пауза и доступные настройки.
- `src/style.css` — адаптивная тема, анимации и поддержка reduced motion. Звук создаётся локально Web Audio API и по умолчанию отключён.
- `docs/SPEC.md` — исходное техническое задание.

Для добавления карточки используйте схему `Card` в `src/types.ts` и уникальный ID. Новые темы можно подключать стилями без изменения движка; тексты и названия категорий централизованы для будущей локализации.

Проект независим от «ГРАДУС ONLINE». Публикация возможна только после отдельного разрешения владельца.
